## Средн.2. Окно с текстовым полем и кнопкой

Файл `task02_text_echo.py` содержит приложение на Tkinter. Пользователь вводит текст в поле, после чего кнопка «Показать» выводит его в отдельной области. Enter выполняет то же действие. Пустой ввод обрабатывается отдельно, кнопка «Очистить» сбрасывает состояние.

Запуск:

```bash
python task02_text_echo.py
```

## Средн.8. Диалог выбора файла

Файл `task08_file_dialog.py` открывает стандартный диалог выбора файла и показывает содержимое выбранного UTF-8 файла. Чтение вынесено в функцию `read_text_file`. Интерфейс обрабатывает `FileNotFoundError`, `PermissionError`, `UnicodeDecodeError`, `OSError` и слишком большой файл. Ошибка показывается пользователю, а приложение продолжает работать.

Запуск:

```bash
python task08_file_dialog.py
```

## Средн.10. Простейший GUI на PyQt5

Файл `task10_pyqt.py` демонстрирует отдельное приложение на PyQt5. В окне есть поле имени, кнопки приветствия и очистки, а также метка результата. Нажатие Enter в поле ввода тоже формирует приветствие.

Установка зависимости и запуск:

```bash
python -m pip install -r requirements.txt
python task10_pyqt.py
```

## Повыш.3. Игра «Кликер»

Файл `advanced03_clicker.py` содержит игру с раундом длительностью 10 секунд. После старта активируется большая кнопка, каждое нажатие увеличивает счёт. Отдельно отображаются оставшееся время, текущий результат и лучший результат. После истечения времени кнопка автоматически блокируется.

Состояние игры вынесено в класс `ClickerGame`, поэтому правила игры проверяются unit-тестами без создания окна.

Запуск:

```bash
python advanced03_clicker.py
```

## Повыш.10. Локальный чат

Файл `advanced10_local_chat.py` реализует локальный TCP-чат с интерфейсом на Tkinter. Один экземпляр программы может запустить сервер, после чего этот же или другой экземпляр подключается к указанному адресу и порту. Для проверки на одном компьютере достаточно использовать `127.0.0.1` и порт `5050`.

Сообщения передаются в виде JSON-строк UTF-8. Сетевой обмен выполняется в фоновых потоках, поэтому окно не зависает во время ожидания данных. Ошибки адреса, порта, подключения и отправки выводятся в интерфейсе. Протокол ограничивает максимальный размер сообщения.

Проверка на одном компьютере:

1. Запустить `python advanced10_local_chat.py`.
2. Оставить адрес `127.0.0.1` и порт `5050`, нажать «Запустить сервер».
3. Нажать «Подключиться».
4. Запустить второй экземпляр программы и нажать «Подключиться» с тем же адресом и портом.
5. Ввести разные имена и обменяться сообщениями.
